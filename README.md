# Google IT Automation with Python Professional Certificate - Practice files

This repository contains the practice files used throughout the courses that are
part of the Google IT Automation with Python Professional Certificate

There's a separate folder for each course.

## Machine Learning Examples

The `ml_examples/` directory contains additional machine learning examples:

- **Logistic Regression Classifier** - A from-scratch implementation using stochastic gradient descent
- **MNIST Classification** - Examples showing common pitfalls and how to improve accuracy
- **[How to Improve Accuracy Guide](ml_examples/HOW_TO_IMPROVE_ACCURACY.md)** - Detailed guide on fixing common issues

See the [ml_examples README](ml_examples/README.md) for more details.
